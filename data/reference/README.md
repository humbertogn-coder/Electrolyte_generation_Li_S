# data/reference

Reference and calibration data. Everything here is small, versionable and sourced.

| File | Content | Status |
|---|---|---|
| `seeds.csv` | Coordinating and diluent seeds (M0), each with the paper it comes from (`reference`, `doi`). | F5DEE and OFE SMILES flagged for confirmation against the papers' SI |
| `salts.csv` | LiFSI and LiTFSI. | ready |
| `tier0_reference_molecules.csv` | Five molecules with the expected tier-0 ordering (H1 success criterion). | numeric DN with source still to fill |
| `li2s8_gfn2_alpb_ether.xyz` | Li₂S₈ reference geometry (GFN2-xTB/ALPB) for the tier-0 affinity. Not a verified global minimum. | ready |
| `tier0_reference_results_gfn2.csv` | Tier-0 results for the 6 reference molecules (xtb 6.7.1, Linux). Regression set for `tests/test_tier0.py`. | ready |
| `joule2021_table1_solubility.csv` | Table 1 of *Joule* 2021 (Liu et al., 5, 2323; doi 10.1016/j.joule.2021.06.009): S₈ and Li₂Sₓ solubility in mM of S atoms for 42 systems, long format (one row per system and species). Regenerated by `build_joule2021_table1.py`; fix transcription errors there. **H3 gate dataset.** | transcribed from the printed table; HME abbreviation and a few footnotes still to confirm |
| `combat_seed.csv` | ComBat / MISPR subset (Atwi and Rajput) for cold-starting the surrogates. | to download |
| `scirep2023_materials.csv` | The 69 solvents, 5 anti-solvents, 2 salts and 1 additive of *Sci. Rep.* 2023 (Lee et al., 13, 20784; names from the SI) with their Table S1 attention score to DME. No solubility values: the COSMO-RS dataset is held by LG Energy Solution. | names transcribed; SMILES to resolve |

Columns of `joule2021_table1_solubility.csv`:

```
system_id, system, category, solvent, solvent_smiles, diluent, salt, salt_conc, temperature_C,
species, solubility_mM_S, approx, ref, note, source
```

`species` takes the values `S8`, `Li2S8`, `Li2S6`, `Li2S4`, `Li2S3`, `Li2S2`, `Li2S`; `category` is `MSE`, `SSE` or `HSE` (moderately, sparingly, highly solvating), as the review organizes them; `approx` marks values printed with "~"; `ref` is the review's own reference number; `solvent_smiles` is filled only for molecular solvents (dot-separated for mixtures), empty for ionic liquids.

Literature Coulombic-efficiency data, if compiled, go in a separate file with the conditions (S loading, E/S ratio, current density, voltage window, paper) as mandatory columns. They are used only as qualitative rank validation, within a single paper.
